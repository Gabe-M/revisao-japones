📤 Importar Vocabulário via JSON ▼

Você pode importar múltiplos termos em lote enviando um arquivo .json. Use a sua IA pessoal (ex: ChatGPT, Claude) para formatar seus dados utilizando o prompt abaixo:

1. Formato JSON Esperado: 
[
  {
    "item": "日本語",
    "leitura": "Nihongo",
    "significado": "Língua Japonesa",
    "categoria": "Vocabulário",
    "notas": "Notas opcionais (opcional)"
  }
]
