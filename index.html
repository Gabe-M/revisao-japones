📤 Importar Vocabulário via JSON ▼

Você pode importar múltiplos termos em lote enviando um arquivo .json. Use a sua IA pessoal (ex: ChatGPT, Claude) para formatar seus dados utilizando o prompt abaixo:

1. Formato JSON Esperado: 
[
  {
    "item": "日本語",
    "leitura": "Nihongo",
    "significado": "Língua Japonesa",
    "categoria": "Vocabulário",
    "notas": "Notas opcionais (opcional)"
  }
]
2. Prompt para sua IA Pessoal:
Salvar no(s) Conjunto(s):
Nenhum arquivo
📥 Importar Baralho Anki (TXT) ▼

Importe termos a partir de um arquivo .txt exportado do Anki. O arquivo deve usar tabulação como separador e seguir o formato padrão de 13 colunas. A categoria de cada termo será detectada automaticamente.
